# Olivia's Portfolio

A personal portfolio website hosted with GitHub Pages at https://oliviaeberwein.github.io/.

## Files
- `index.html`: homepage, SEO metadata, JSON-LD
- `style.css`: responsive visual design
- `script.js`: small enhancement
- `robots.txt`, `sitemap.xml`: crawler guidance
- `llms.txt`: optional AI-oriented site summary
- `404.html`: custom not-found page
- `manifest.json`: web app metadata

## Publish
Use GitHub Pages with the `main` branch and root (`/`) as the publishing source.
